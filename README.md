# 집엔 가야지

**서울권 대학생을 위한 밤 귀가 가이드.**

배포 사이트: [집엔 가야지](https://jib-en-gayaji.vercel.app)

과제·동아리·모임을 마친 뒤 집이나 기숙사로 돌아갈 때 **늦어도 언제 출발해야 하는지** 먼저 확인하는 뉴비톤 프로젝트입니다. 지하철 환승 지점에서 5분·10분 늦어졌을 때의 영향을 비교하고, 출발 후에는 시간 기반 예상 이동 안내를 제공합니다.

## 안내 지역과 대상

- 현재 서비스 안내 범위는 **서울권**이며, 주요 대상은 서울권에서 대중교통으로 귀가하는 대학생입니다.
- 서울권 안에서도 API가 제공하는 노선·정류장·시간표에 따라 조회 가능 여부가 다릅니다. 서울권 전 구간의 막차 확인을 보장하지 않습니다.
- 장소 검색에 다른 지역이 나타날 수 있으나, 그 지역의 경로·막차 안내는 지원 범위에 포함하지 않습니다. 지역 안내 문구는 전국 지원을 뜻하지 않으며 행정구역별 검색 차단 기능을 구현한 것은 아닙니다.
- 명칭은 “늦게까지 함께해도, 집엔 가야지”라는 대학생의 일상적인 귀가 고민을 담았습니다.

## 이용 흐름

1. 출발지·목적지를 검색 결과에서 선택하고 출발 예정 시각을 입력합니다.
2. `경로 찾기`를 누르면 **출발 마감 → 선택한 경로 → 다른 경로 비교** 순서로 결과가 표시됩니다. 출발 마감은 경로 조회 후 별도로 확인합니다.
3. `출발`을 누르면 경과시간, 하차 예상 시각과 직선 경로 위 캐릭터가 갱신됩니다. `안내 종료`를 누르면 초기화됩니다.
4. 경로 지점을 누르면 상세 정보가 펼쳐집니다. 이동 설정, 승차·하차 순서, 도보 조회와 지하철 지연 분석은 필요할 때 펼칩니다.

캐릭터는 **GPS 현재 위치가 아닌 시간 기반 예상 위치**입니다. 실제 탑승 여부나 차량 위치를 확인하지 않습니다.

## 주요 기능

- 출발지·목적지와 출발 날짜·시각 입력
- 대중교통 정류장 검색과 카카오 장소 검색을 함께 제공
- 지하철 / 버스 / 버스+지하철 경로를 여러 카드로 비교
- 소요시간, 예상 도착 시각, 환승 횟수와 승·하차 순서 표시
- 직선 경로의 출발·승차·환승·하차 지점을 눌러 상세 정보 확인
- 시간표가 확인된 **지하철 경로에만** 정상 / 5분 / 10분 지체 분석 표시
- 선택한 경로의 막차 예정정보·심야 시간표를 이용한 출발 마감 참고값
- 출발 버튼, 경과시간, 하차 예상 시각과 경로 위 캐릭터 이동
- 크림색 검색 영역·남색 귀가 플랜·라임색 출발 마감, 작은 경로 카드와 접이식 상세 정보
- 열차를 놓치는 지점에서 지하철 대안 재조회
- 선택한 지점에서 목적지까지 카카오 도보 거리·시간·도착 예상 시각 조회
- 같은 지점에서 목적지까지 택시 예상 요금·차량 이동시간·통행료 별도 조회

## 실행하기

**Python 3.10 이상**이 필요합니다. 실행에 별도 Python 패키지나 Node.js 설치는 필요 없습니다.

```sh
git clone https://github.com/pcy1984/newbiethon_25.git
cd newbiethon_25
python backend/app.py
```

터미널에 표시된 [http://localhost:8765/](http://localhost:8765/)를 엽니다.

Windows에서는 `start.cmd`를 더블클릭해도 됩니다. 실행 창을 닫으면 서버가 종료됩니다.
포트는 기본 8765이며 로컬 서버는 `127.0.0.1`에서만 실행됩니다. Vercel에서는 별도의 Python 함수 진입점으로 실행합니다. GitHub에 올리는 것만으로 웹 서비스가 배포되지는 않습니다.

## API 설정

1. 프로젝트 루트의 `.env.example`을 같은 위치의 `.env`로 복사합니다.
2. 아래 항목에 발급받은 키를 입력합니다.
3. 실행 중인 서버를 종료하고 다시 실행합니다.

| 환경변수 | 용도 |
| --- | --- |
| `SEOUL_TRANSIT_API_KEY` | 서울교통공사 최단경로이동정보: 지하철 경로·시간표 |
| `SEOUL_BUS_PATH_API_KEY` | 서울시 대중교통환승경로: 정류장 검색·버스·지하철 경로 |
| `SEOUL_BUS_STATION_API_KEY` | 서울시 정류소정보: 정류장·노선별 막차 예정정보 |
| `KAKAO_REST_API_KEY` | 카카오 장소 검색·도보와 카카오모빌리티 택시 예상 요금 |
| `JOURNEY_TOKEN_SECRET` | Vercel 경로 검증용 무작위 비밀값(32자 이상), 로컬에서는 생략 가능 |
| `PORT` | 로컬 서버 포트, 기본 `8765` |

공공데이터 API는 해당 서비스의 활용신청이 승인되어 있어야 합니다. 카카오는 앱의 카카오맵 사용 설정과 API 이용 가능 여부를 확인해 주세요.
`KAKAO_JAVASCRIPT_KEY`는 현재 화면에서 사용하지 않으므로 비워 두어도 됩니다.

실제 키가 있는 `.env`는 Git에서 제외됩니다. 저장소에는 값이 비어 있는 `.env.example`만 포함합니다.
REST 키는 서버에서 사용하며 프런트엔드에 전달하지 않습니다. 현재 서울시 버스 연동은 공식 `http://ws.bus.go.kr/api/rest/` 주소를 사용하므로 해당 요청 구간은 HTTPS 암호화가 적용되지 않습니다.

## 키 없이 실행

모든 API 키가 비어 있으면 가상 예제 모드가 표시됩니다.
예제 버튼으로 홍대입구역 ↔ 강남역 또는 건대입구역 ↔ 서울역을 선택해 화면과 시간 계산 흐름을 확인할 수 있습니다.
가상 예제는 실제 운행 정보가 아니며, API 오류를 예제 결과로 대체하지 않습니다.

## 계산 기준과 한계

- 지연 분석은 **사용자가 출발·환승 지점 한 곳에서 지체되는 상황**입니다. 열차 자체의 지연을 예측하거나 실시간 도착정보를 추적하지 않습니다.
- 지하철은 모든 승차 구간의 시간표가 확인된 경우에만 분석합니다. 버스와 혼합 경로에는 지연 분석을 표시하지 않습니다.
- 버스·혼합 경로의 전체 소요시간은 제공처의 기본 시간에 설정한 여유를 더한 예상값입니다. 구간별 시간이나 배차 시각이 제공되지 않는 항목은 미확인으로 남습니다.
- 출발지에서 첫 승차 지점까지는 사용자가 입력한 이동시간을 적용합니다. 이미 승차 지점에 있다면 0분으로 설정하세요.
- 지하철 출발 마감은 22:00~다음 날 02:00의 표본 조회를 이용한 참고값이며, 모든 막차를 빠짐없이 탐색한 확정 시각이 아닙니다.
- 버스 출발 마감은 해당 정류장의 막차 예정정보와 확인된 구간 소요시간을 이용한 예상값입니다. 현재는 조회 당일 낮~심야 출발 조건에서 확인합니다.
- 도보 경로는 별도 버튼으로 조회합니다. 도보 결과가 전체 대중교통 소요시간이나 출발 마감에 자동 반영되지는 않습니다.
- 이동 안내는 `출발` 버튼을 누른 시각부터 실제 경과시간으로 갱신합니다. 브라우저가 백그라운드에 있어 갱신이 늦어져도 다음 갱신 때 경과시간을 다시 계산합니다.
- 시간표가 모두 확인된 경로는 **조회 당시 경로의 이동·대기 간격을 재생**합니다. 출발 버튼을 누른 시각에 맞춰 실제 열차 시간표를 재조회하거나 막차 탑승 가능성을 다시 판정하지 않습니다. 입력한 출발 예정 시각과 실제 출발 시각이 달라졌다면 경로를 다시 검색하세요.
- 버스 등 구간 시간이 없는 경로는 전체 예상시간에서 접근·여유시간과 확인된 구간 시간을 뺀 나머지를 미확인 구간에 균등 배분합니다. 추정 근거가 부족하면 출발 안내를 비활성화합니다. 이 추정은 막차 판정에 사용하지 않습니다.
- 캐릭터의 종료 지점은 **최종 하차역·정류장**이며 집 도착을 뜻하지 않습니다. 안내 종료, 경로·검색 입력 변경, 새로고침 시 진행 상태는 초기화되며 별도로 저장되지 않습니다.
- 경로가 표시되거나 여유가 있다고 나와도 실제 탑승·귀가를 보장하지 않습니다. 운휴·정체·현장 이동시간은 별도로 확인해야 합니다.
- 조회 결과가 부족하다는 것은 귀가할 방법이 없다는 뜻이 아닙니다. 지역 전체의 모든 노선 지원을 보장하지 않습니다.
- 택시는 경로 지점을 선택하고 `지점 상세 · 도보·택시` → `여기서 택시 타면?`에서 조회합니다. 버튼을 누를 때만 호출하며 실제 택시 호출·예약·결제는 하지 않습니다.
- 택시비는 카카오모빌리티 자동차 경로 응답의 `summary.fare.taxi` 참고값입니다. 요금이 없거나 0이면 무료가 아닌 미확인으로 표시합니다. 통행료는 제공값을 따로 보여주며 택시비에 임의 합산하지 않습니다.
- 심야·시외 할증 및 호출료 포함 여부는 확인되지 않았습니다. 실제 요금과 다를 수 있으므로 탑승 전에 확인해야 합니다. 도보 거리를 택시 요금으로 환산하거나 자체 할증률을 덧붙이지 않습니다.
- 택시 예상 탑승 시각이 현재 분이면 현재 교통정보, 미래면 미래 운행 정보 API를 사용합니다. 과거 시각은 거절하며, 도착 예상에는 배차 대기·승차 지점까지 이동을 포함하지 않습니다.

## Vercel 배포

프로젝트 루트에서 Vercel에 연결해 배포합니다. `vercel.json`은 `frontend/`를 정적 화면으로, `api/index.py`를 Python 함수로 구성합니다. 로컬 실행과 배포 실행은 분리되어 있습니다.

Vercel의 Production 환경변수에 네 가지 API 키와 `JOURNEY_TOKEN_SECRET`을 등록한 후 배포해야 합니다. 키가 든 `.env`는 업로드하지 않습니다. `.vercelignore`로 환경파일·테스트·임시 확인 스크립트도 배포에서 제외합니다.

서버가 바뀌어도 경로 선택이 유지되도록, 배포 환경에서는 5분 만료의 서명된 경로 스냅샷을 사용합니다. 여기에는 API 키가 없으며 검색 조건과 경로가 포함됩니다. 암호화된 토큰이 아니므로 공유하지 마세요. 변조·만료·입력 불일치가 감지되면 다시 검색하도록 안내합니다.

기본 Vercel 도메인은 자동 인식합니다. 별도 도메인을 연결한다면 `APP_ALLOWED_HOSTS`에 허용할 호스트명을 쉼표로 구분해 등록하세요. API 호출 한도·호스팅 사용량은 각 제공처에서 관리하며 유료 요금제 전환은 별도로 결정해야 합니다.

  bus_transit.py     버스·혼합 경로·정류장 막차

frontend/

별도 로그인이나 데이터베이스는 없습니다. 조회 결과는 서버 메모리에 잠시 보관하며 사용자의 검색 입력을 파일로 저장하지 않습니다.

## 테스트

Python 테스트와 JavaScript 테스트를 각각 실행합니다. JavaScript 테스트에는 Node.js 20 이상을 권장합니다.

```sh
python -m unittest discover -s tests -p "test_*.py"
node --test
```

테스트는 모의 API 응답을 사용하므로 실제 키가 필요 없습니다. 경로·막차·지하철 지체 계산, API 오류 처리, 시간 기반 이동의 단계 전환·자정 경과·출발/중단·입력 변경을 검증합니다. 자동 테스트는 실제 운행 정보의 정확성이나 브라우저의 시각적 검수를 보장하지 않습니다.
